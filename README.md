# PingUp – Client Side (Frontend)

PingUp is a modern social media web application frontend built with **Next.js** and **React**, designed to deliver a smooth, interactive, and responsive user experience. This repository contains the client-side implementation of the PingUp platform.

## 🛠️ Tech Stack

### Frontend Framework & Core
- **Next.js 16** – App Router & optimized performance
- **React 19** – Component-based UI development

### State Management & Data Fetching
- **TanStack React Query** – Server state management & caching
- **Axios** – API communication

### Authentication
- **Firebase Authentication** – Secure login & user management

### UI & Styling
- **Tailwind CSS** – Utility-first CSS framework
- **DaisyUI** – Pre-built Tailwind components
- **HeroUI** – Modern UI system
- **React Icons** – Icon library

### Forms & User Interaction
- **React Hook Form** – Efficient form handling & validation
- **SweetAlert2** – User-friendly alerts & confirmations

### Animations & Media
- **Framer Motion** – Smooth animations & transitions
- **Lottie React** – Lightweight animations
- **Swiper** – Responsive sliders & carousels

### Utilities
- **Moment.js** – Date & time formatting
- **React Tabs** – Tab-based navigation

## ✨ Key Features
- User authentication (Login / Register)

- Responsive UI for all screen sizes
